# Admin Absensi Karyawan

Halaman admin sederhana untuk technical test Frontend Web Developer Intern Ayo Bermimpi x JURU.

## Fitur

- List data karyawan yang telah absen.
- Input data absensi: nama, alamat, jenis kelamin, tanggal absen, jam masuk, dan jam keluar.
- Update dan delete data absensi.
- Sort by tanggal, nama, jenis kelamin, jam masuk, dan jam keluar.
- Pagination dengan pilihan jumlah data per halaman.
- Data tersimpan di `localStorage`, sehingga tetap ada setelah halaman direfresh.
- Tampilan admin mengikuti struktur BackStrap/CoreUI-style dashboard dengan HTML, CSS, dan JavaScript murni.

## Cara Menjalankan

Buka file `index.html` langsung di browser.

Opsional, jalankan server lokal:

```bash
python3 -m http.server 8080
```

Lalu buka `http://localhost:8080`.

## Struktur

```text
|-- css/
|   `-- styles.css
`-- js/
    `-- app.js
```
